# Default backgrounds | Enterprise Edition

One per workspace, in this edition's theme. Each is a vector file with no fixed size: a display draws it at its own resolution, the field fills any shape of screen, and the emblem and words stay whole on every screen from 4:3 to 21:9. On a taller screen, such as a phone held upright, the sides are cut; a layout for that shape does not exist yet. Nothing in them is a bitmap, so nothing is stretched. Generated from the design tokens; the emblem is the one on the covers.

`pcp-core.svg` is the default. The others are used when a workspace has that module in its profile.
