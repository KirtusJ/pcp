# This edition

**Edition:** Enterprise. `EDITION.json` beside this file is the same statement for a program.
**Licensed to:** the organization named in a written agreement with the rights holder, on the terms of that agreement. The license supplied with the edition states what is permitted; this file adds and removes nothing.

**The method does not vary with the edition.** The method text in `method/` is the same bytes in every edition, and so is every other file of this plugin outside this folder.

**People and roles.** The organization assigns roles and groups. Whoever administers does not assess, and an auditor writes nothing. The organization may set a floor that every installation meets; an installation may be stricter and never laxer.

**Standards.** Every field of a standard is available. Where the organization has set a floor, work under it and do not ask the person to relax it.
