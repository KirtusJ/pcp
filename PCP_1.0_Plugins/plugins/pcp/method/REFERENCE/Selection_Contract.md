# Module-selection contract | ACR 1.0

Core applies when ACR is commissioned under an authorized task or governing policy. The following six specialist modules use **one common rule**: Mathematics, Science, Engineering, Cryptography, Statistics and Quality Assurance are all released and available, but **distribution/installation alone does not select any of them**. Exact selection comes from a governing task, Review mandate, or standing policy.

No special approval ceremony is added for Statistics or QA. No module automatically activates another specialist. No Review is required for ordinary authorized work merely because a specialist is selected. Independently applicable statutory, professional, security, scientific, engineering and safety obligations cannot be waived by omitting a specialist from an ACR task record.

**Examples:** A mathematical proof may use Core + Mathematics. A scientific sampling question may use Core + Science + Statistics. A software quality inspection may use Core + QA (plus Engineering when the task actually requires it). These examples are not automatic rules or mandatory pairs.

**Selection-preflight tool:** checks input shape and records caller-asserted selections only. It cannot independently grant an authorized task, verify the evidence, decide module applicability for arbitrary work, or override the host's permissions.
