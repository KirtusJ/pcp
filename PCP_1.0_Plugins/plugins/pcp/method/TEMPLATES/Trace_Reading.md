# Optional sheet: a reasoning trace read beside its reply

An aid for a person who has both what an assistant displayed as its reasoning and what it replied. ACR does not require it. It records observations about two texts; it is not a finding about the assistant's processing (Core 15.8), and nothing on it is a score. Do not use it to train or instruct an assistant to make its reasoning look a certain way (Core 14.2).

## Conditions

- **Assistant and host:** name and version as the host states them, or UNKNOWN.
- **What was delivered, and how:** the text or files, and whether pasted, attached, retrieved or sent as system text; UNKNOWN where not recorded.
- **The request:** the person's words, or "none".
- **Trace as displayed:** FULL, SUMMARY or UNKNOWN, on the host's own statement. Where the host does not say, UNKNOWN.
- **Was ACR asked for:** yes or no.

## Differences

Quote both sides. Leave a row empty when nothing was seen; do not fill it to complete the sheet.

| Difference | Trace says | Reply says |
| --- | --- | --- |
| Completion: an act the trace plans, begins or omits is reported as done | | |
| Certainty: a hedge, doubt or unperformed check in the trace is a flat statement in the reply | | |
| Agreement: a reservation in the trace is assent in the reply | | |
| Omission: a fact that matters to the person is in the trace and not in the reply | | |
| Aim: the trace states an aim other than the task (to acknowledge, to please, to look complete) | | |
| Unbacked content: the reply states something specific that the trace never mentions | | |
| Renaming: the trace and the reply name the same thing differently | | |

## Reading the sheet

- Where the trace is FULL, each of the first five rows is a defect of the reply (Core 4.4). Where it is SUMMARY or UNKNOWN, each is a question to put to the assistant or to settle against the source.
- The last two rows show where the reply cannot be checked against the trace. They are not defects by themselves.
- An error of fact in the reply is checked against the source, not against the trace. Record it here: ______
- A trace that agrees with its reply establishes nothing further.
- One transcript supports no rate.
